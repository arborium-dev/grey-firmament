the idea

THEME: The stars reward those who dare to improvise

Setting: Year 8888, kind of cyberpunk


Racoon Name: Racchias

Concept: 
This is a top-down immserive-sim where you are a racoon who is climbing a clocktower to finally see the stars (theres smog in beijing)

At the start of each level, you have 3 "Star Slots". You're shown a list of 7~ items which each consume a different number of star slots. Once you've filled the number of star slots that you want, you proceed into the level only using those items.

Each level will contain several unique elements like explosives, glass, unique enemy types, water(?), and other hazards that can be interacted with in unique ways.

At the end of the level, if you didn't use all of your star slots, you're rewarded for improvising by getting permanent perks (such as higher health, etc.)

These mechanics create a loop of risk-reward where you have to improvise on the fly with minimal resources, and if done succesfully you're rewarded for the next level.
